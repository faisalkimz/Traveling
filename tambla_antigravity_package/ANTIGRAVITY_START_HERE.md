# TAMBLA — ANTIGRAVITY START HERE

You are building **Tambla**, a Uganda-first ride-hailing mobile application in **React Native using JavaScript/JSX**.

## Read these files before writing code

1. `reference/Tambla_reference_design.png` — **PRIMARY VISUAL SOURCE OF TRUTH**.
2. `TAMBLA_MASTER_BUILD_SPEC.md` — complete product, UI, architecture, screen and quality specification.
3. `DEVELOPMENT_WORKPLAN.md` — implementation order and acceptance gates.

## Mandatory first action

Before coding, inspect the reference image carefully and write a short internal visual inventory covering:
- screen structure
- colors
- typography hierarchy
- spacing rhythm
- card geometry
- button geometry
- map proportions
- navigation
- icon style
- light/dark surfaces
- recurring UI patterns

Then build the design system from that visual inventory.

## Non-negotiable rule

The reference image is **not inspiration**. It is the benchmark. Reproduce the supplied screens with very high visual fidelity. Missing screens must look like natural extensions of the same product, not newly invented redesigns.

Do not proceed to broad feature development until the 10 reference screens are visually close to the supplied image.

## Technology

- React Native
- JavaScript
- JSX
- Android-first, iOS-compatible
- Production-grade component architecture
- UI-first phase; mock data is acceptable

## Product identity

App name: **Tambla**
Market: **Uganda**
Currency: **UGX**
Phone prefix: **+256**
Primary payment patterns: **MTN Mobile Money, Airtel Money, Cash, Tambla Wallet, Card**
Ride categories: **Car, Moto/Boda, Delivery**

## What not to do

Do not:
- redesign the supplied screens
- introduce AI-looking visuals
- add robots, mascots or chatbot styling
- add random gradients or glassmorphism
- over-round every component
- make giant web-dashboard cards
- use lorem ipsum or fake US addresses
- use dollar currency
- put the entire application in `App.jsx`

## Definition of success

A reviewer should look at the app and think:

> “A real senior mobile product team designed and engineered this.”

Not:

> “An AI generated a taxi app.”

Start with the reference screens and follow the workplan exactly.
